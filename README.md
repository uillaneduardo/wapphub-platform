# WappHub Platform

Frontend administrativo e comercial do ecossistema WappHub.

O projeto reúne duas áreas distintas:

- **WappHub Admin**: operação interna da WappHub.
- **Minha Conta**: administração da relação comercial da organização contratante com a WappHub.

## WappHub Admin

Mínimo previsto:

- Empresas contratantes.
- Produtos.
- Planos.
- Recursos.
- Vinculação de recursos a planos.
- Preços, incluindo valor R$ 0,00.
- Assinaturas.
- Assentos e adicionais.
- Overrides/cortesias de recursos.
- Situação de integrações.
- Auditoria administrativa.

## Minha Conta

Mínimo previsto:

- Organização atual.
- Assinatura.
- Plano.
- Recursos contratados.
- Assentos contratados, utilizados e disponíveis.
- Gestão comercial básica.
- Faturamento básico.
- Conta pessoal.

## Regra de preço

Preço `0` é válido. Isso permite, por exemplo, que a própria WappHub possua uma organização e uma assinatura interna gratuita sem exceções hardcoded.
