# Rotas do WappHub Platform

As rotas devem ser reais e visíveis na barra de endereço.

## WappHub Admin

- `/admin`
- `/admin/organizations`
- `/admin/organizations/:organizationId`
- `/admin/products`
- `/admin/products/:productId`
- `/admin/plans`
- `/admin/plans/:planId`
- `/admin/features`
- `/admin/features/:featureId`
- `/admin/subscriptions`
- `/admin/subscriptions/:subscriptionId`
- `/admin/audit`

## Minha Conta

- `/account`
- `/account/subscription`
- `/account/features`
- `/account/seats`
- `/account/billing`
- `/account/profile`

Rotas e menus devem respeitar permissions e contexto da Organization.
